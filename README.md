映色是一款面向大疆相机视频的本地色彩处理工具。通过浏览器批量导入素材、预览并应用 LUT，在本机使用 FFmpeg 导出视频；支持自定义 LUT、帧率选择、NVIDIA 硬件编码，以及队列暂停、继续和取消。项目以 DJI Osmo Action 4 的 D-Log M → Rec.709 色彩还原为示例和已验证场景；其他大疆机型请根据相机型号和拍摄色彩模式选择匹配的 LUT，不能假设 Action 4 的还原 LUT 适用于所有机型。

## 启动

克隆或下载仓库后，双击 **打开工作台.bat**。需要 Windows 10 / 11、Python 3.9+，无需安装 pip / npm 包。
源码仓库不包含 FFmpeg 可执行文件或大疆官方 LUT。首次运行时程序会尝试下载缺少的文件；也可以手动将 FFmpeg 的 `ffmpeg.exe` 和 `ffprobe.exe` 放入 `tools` 文件夹，并将大疆官方 Action 4 D-Log M → Rec.709 LUT 放在项目根目录，命名为 `Action4_DLogM_Rec709.cube`。依赖准备完成后可离线处理。FFmpeg 需包含 `zscale` 和 `lut3d`；显卡加速需兼容的驱动，检测失败时会回退 CPU。

请用 Chrome 或 Edge 打开工作台。

## 使用

1. 批量添加视频，勾选需要处理的素材。
2. 选择滤镜，在预览中拖动分割线对比效果。
3. 点击右侧 **选择文件夹**，使用浏览器自带的目录选择框授权保存位置。
4. 先做 8 秒试片，或直接开始批量处理。成片完成后自动保存到选定文件夹。

右侧只有浏览器原生目录选择按钮，不包含自制目录浏览器。
浏览器显示所选文件夹的名称；浏览器不会把完整磁盘路径提供给网页。

转码在本机后台执行；成片写入所选目录由浏览器完成。**保存时请保持网页打开**。
关闭网页后当前视频仍可完成；待保存成片达到限制时，后续队列会暂停。重新打开后在授权有效时继续保存并自动恢复队列；需要时重新选择同一文件夹授权。
“查看处理结果”中始终可以直接下载已完成的成片。

## 滤镜列表与队列

- “＋ 导入 LUT”可一次选择多个 `.cube` 文件加入滤镜列表。
- 每张滤镜卡片右上角的“×”直接从列表移除；内置和自定义滤镜都支持。
- 误移除可以点“撤销”或“恢复已移除的滤镜”。原 LUT 文件和排队中的任务会保留。
- 处理队列通过右上角“处理队列”按钮打开，开始任务后自动弹出；收起面板不会中断处理。
- 队列右上角“全部暂停”会停住当前 FFmpeg 转码并阻止后续任务启动，按钮变为“继续处理”；继续后保留当前进度接着编码。已完成成片的浏览器保存仍会继续。
- “全部取消”一次取消所有页中正在转码和等待处理的任务，停止当前转码并清除其未完成临时文件；已完成成片保留。取消后可对单个任务点击重试，从头重新编码。
- 暂停状态会随工作台记录保存；刷新网页保持暂停。退出后台服务或重启电脑仍按中止任务处理，暂停不等于跨重启断点续编。

## 大批量素材

- 素材库和弹窗队列每页显示 40 条；“全选”和批量应用滤镜覆盖所有页。
- 后台一次只转码 1 段视频，读取视频信息最多并行 2 段。选中的素材全部读取完成后才能开始，避免漏掉尚在读取的视频。
- 界面每 2 秒更新状态；素材未变化时不重复传输整份素材数据，后台合并频繁的元数据存盘。
- 在开始下一段前检查缓存：待保存成片达到 2 个，或其合计体积达到 1 GiB 时暂停后续转码，保存并清理缓存后自动继续。这是启动下一段的条件，单个长视频的临时文件仍可能超过 1 GiB。
- 转码前也检查临时磁盘剩余空间，空间不足时暂停。最终成片所在磁盘仍需留出足够空间，建议使用内置硬盘或稳定连接的移动硬盘。
- 数百段大视频建议使用素材库的文件夹选择或“输入本地路径”引用原片文件夹；浏览器选视频 / 拖入会复制原片到本地缓存，占用额外磁盘空间。保存位置继续使用右侧浏览器原生目录选择。
- 大批量运行时保持网页打开，电脑不要睡眠。退出后台服务或重启电脑后，未完成任务会标为中止，可在队列中重试；此版本不支持视频内部断点续编。

## 色彩与格式

- 输入 DJI D-Log M 时先完整技术还原，再叠加风格；标准 Rec.709 素材选择对应输入类型。
- 内置官方还原、柔和日光、暖调胶片、冷调纪实、黑白银盐，后四种为本工具的风格调整。
- 支持纯 3D `.cube`，可选择作为技术还原或还原后的风格 LUT；强度只控制风格部分。
- 默认“自动 · 显卡优先”，通过预检后使用 NVIDIA H.265 10-bit；也可手动选择 CPU 或 H.264。
- 默认码率目标接近原片；也可选自动码率来减小体积。相同体积不代表无损，套用 LUT 仍需重新编码。
- 帧率可选保持原帧率、24、25、30、50、60、120 fps。“保持原帧率”会保留原片的实际帧率，包括 29.97 等小数帧率；选择整数帧率则按所选值导出。改变帧率保持播放速度和时长；升帧率采用重复帧，不进行光流或 AI 补帧。
- 新增“大疆参考增强”，根据本次提供的大疆导出样片对齐色彩浓度与明暗观感；这是参考增强预设，不代表复现大疆内部算法。原有官方技术还原保持独立可选，参考增强的强度 0% 回到标准还原。
- “叠加二次增强”可独立用于其他内置滤镜和自定义 3D LUT，增强强度与风格强度分别调节，支持批量应用。处理顺序为基础还原 / 技术 LUT → 所选风格 → 二次增强。
- 二次增强使用当前 LUT 自身的曲线，100% 对应 85% 二次效果混合；对风格 LUT 使用其已设定的风格强度，对技术 LUT 的首次还原保持完整。关闭或强度 0% 不改变原处理。
- 原有“大疆参考增强”预设继续保留；选中该预设时独立增强不会再重复叠加。二次应用 LUT 属于风格处理，效果随 LUT 而变，请先预览。
- 保留输入分辨率、帧率和音轨，标记为 SDR Rec.709。
- NVIDIA 不兼容时自动回退 CPU H.265 10-bit；不会要求先升级驱动。
- 预览为处理后的 JPEG 帧，检查实际压缩效果请用试片。

原片保留。LUT 不会自动修复拍摄曝光或白平衡差异；导出不复制相机陀螺仪等私有数据轨。

## 本地文件

后台转码只使用 `.runtime/render-cache` 临时缓存。浏览器确认成片完整保存后，自动清除对应缓存，只在所选目录保留最终文件。
保存中断或失败时，缓存保留用于重试。此规则适用于 1.5 之后的新任务。
素材和任务记录在 `.runtime`；详细转码日志在 `.runtime/logs`。
通过浏览器导入视频会建立本地副本，大体积素材也可用路径导入直接引用原片。

右上角设置可退出后台服务；只关闭网页不会结束转码。

## 开发

```powershell
python .\server.py
python .\server.py --port 8765 --no-browser
```

服务仅监听 `127.0.0.1`。`web/browser-output.js` 管理浏览器授权的目录和成片流式保存。
没有 CDN、外部字体或统计服务。

目录选择和文件流写入使用 [File System Access API](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)。
程序按浏览器返回的目录句柄保存文件，不拼接或猜测磁盘路径。
